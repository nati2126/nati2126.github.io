YOLOv8's last Concat joins box coordinates (0–640 px) with class scores (0–1). One UInt8 scale for both rounds every score to zero. Keeping the 24 decode nodes in FP32 restores accuracy, and 63 of 64 convolutions stay INT8 at 3.5× smaller.

Single-laptop results on a 128-image set; differences around 0.01 mAP aren't meaningful. Hover a bar for details.

  • Built a YOLOv8 detection API that serves one endpoint from PyTorch, ONNX Runtime, OpenVINO or TensorRT, chosen by configuration, with a reproducible accuracy, latency and memory benchmark across backends.
  • TensorRT FP16 reached 13.8 ms per image (72 img/s), 6.7× faster than PyTorch on CPU with no accuracy loss.
  • Traced a naive INT8 model scoring 0 mAP to box coordinates and class scores sharing one quantization scale. Keeping the decode tail in FP32 recovered 0.430 mAP50-95 (FP32: 0.444) at 3.5× smaller size.
  • Layered FastAPI app with Pydantic v2 and structured logging; ruff, strict mypy and pytest run in GitHub Actions CI.

03.2 — M.Sc. thesis / Federated learning

BEFLearn

One-shot nested pruning that sizes each federated client's model to its bandwidth.

fig. 3 — nested sub-models, pruned once on the server CIFAR-10 · VGG-11-BN · 10 clients · 20 rounds
side = width κ · area ≈ share of parameters
  1. High κ 1.00 9.63M params · 36.72 MB · 2 clients on 10 Mbps
  2. Mid κ 0.50 2.41M params · 9.19 MB · 3 clients on 2 Mbps
  3. Low κ 0.25 0.60M params · 2.31 MB · 5 clients on 0.1 Mbps
  4. Low ⊆ Mid ⊆ High. The server averages each weight over the clients that trained it.
−69.3% total communication 367.0 → 112.5 MB per round
48.9 → 3.1 min round-gating upload slowest client, per round
−0.93 pp accuracy vs unpruned FedAvg 67.47% vs 68.41%, inside the ≈1 pp run-to-run noise
  • Designed server-side, one-shot nested pruning that sizes each client's model to its bandwidth. Constrained clients do no pruning work during training.
  • Cut total communication by 69.3% and the slowest client's upload from 48.9 to 3.1 min, within 1 pp of unpruned accuracy.
  • Nested sandwich training raised the two smallest sub-models' standalone accuracy from 15% and 30% to 61% and 62% at no extra communication cost.
  • Results are reported as mean ± std over three seeds, with the simulator's own repeatability floor measured and stated.

03.4 — Networking / Security

MiniTor

A Tor-style onion routing network in Python, with authenticated encryption at every hop.

fig. 5 — one message, three layers, three hops building circuit
Directory server relays register · client discovers
  1. Clientwraps 3 AES-GCM layers
  2. Entrypeels layer 1
  3. Middlepeels layer 2
  4. Exitpeels layer 3 · exit policy
  5. Destinationplaintext
  • Built a Tor-style network with RSA-OAEP key exchange and AES-GCM authenticated layers, so each relay can remove only its own layer and knows only the previous and next hop.
  • Fixed-size cells, replay protection and exit policies, plus a directory server for relay registration and discovery.
  • End-to-end tests run in CI on Linux, Windows and macOS.
