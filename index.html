Profile

I'm a software engineer at the Ethiopian Artificial Intelligence Institute, where I build and optimize computer vision systems and the FastAPI services that put them into use.

Most of the job is taking something that works in a research notebook and making it fast, tested and documented well enough for a team to deploy and maintain. That means reading model outputs closely, finding the cases where they fail, and fixing the reason rather than the symptom.

I trained as an electrical and computer engineer and recently finished an M.Sc. in Computer Engineering. My grounding is in algorithms, data structures and distributed systems, and I'm happiest on work where correctness matters and the reasoning has to be explained clearly in writing.

Vision Inference Microservice

An object-detection API: upload an image, get back labelled bounding boxes.

Response shape is illustrative. 42.15 ms is the sample timing from the project README.

  • Serves YOLOv8 object detection over a versioned FastAPI REST API: POST /api/v1/detect returns labels, confidence scores, bounding boxes and inference timing, and GET /api/v1/health reports model status.
  • Layered architecture with thin route handlers, a service layer for orchestration, an isolated model layer and shared core config, so the model can change without touching the API.
  • Pydantic v2 validation, structured JSON logging with structlog, and environment-based config for model, confidence threshold and compute device (CPU, CUDA or Apple MPS).
  • Multi-stage Docker build, docker-compose and Makefile targets, an async test suite with pytest and httpx, and auto-generated Swagger and ReDoc docs.
